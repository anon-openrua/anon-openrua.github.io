Setup

We run OpenRUA on a Franka Panda arm. Using Codex + GPT-6 Astra (high reasoning effort), the agent operates the robot through ROS 2, observes real RGB-D inputs, and writes and executes programs to complete each task. Every trial starts with a fresh task workspace and agent session, with generic robot documentation and tools but no solutions carried over from previous trials.

Each video is the fixed camera view of one complete trial, played at 10×. The counter at the top left shows the real elapsed time. Faces and identifying marks in the lab are blurred.
