OpenRUA: Robot-Use Agents Are Zero-Shot Visuomotor Policies

Physical-robot experiments with OpenRUA · anonymous supplementary material for the rebuttal

Setup

We run OpenRUA on a Franka Panda arm. Using Codex + GPT-6 Astra (high reasoning effort), the agent operates the robot through ROS 2, reads raw RGB-D images from a fixed front camera, a fixed side camera and a wrist camera, and writes and executes programs to complete each task. Physical time runs continuously while the agent reasons.

Every trial starts zero-shot from a fresh workspace and agent session, with generic robot documentation and tools only; no code, notes or experience carry over from earlier trials. Each task has three trials that start from different initial scenes, changing both the tabletop layout and the arm's starting pose. Each trial has a 30-minute limit, and success is judged on site from the final scene.

Each video is the fixed front camera view of one trial, played at 10×; the counter at the top left shows the elapsed recording time. The time under each video is the agent's running time, including model reasoning, code execution, robot motion and any recovery. Faces and identifying marks in the lab are blurred.
