OpenRUA: Robot-Use Agents Are Zero-Shot Visuomotor Policies

Physical-robot experiments with OpenRUA · anonymous supplementary material for the rebuttal

Setup

OpenRUA is built on standard ROS 2 and does not rely on anything specific to simulation, so it naturally carries over to real robots without adding a single line of sim-to-real engineering code. Here, we run OpenRUA on a Franka Panda across 10 diverse manipulation tasks (spanning plate and container placement, cup nesting, bottle uprighting, and multi-step manipulation) using Codex + GPT-6 Astra (high reasoning effort). Physical time continues during agent thinking, while the agent reads real RGB-D camera inputs (from fixed front, fixed side, and wrist cameras), writes ROS 2 programs, and executes them on the robot.

To test generality under a strict real-world setting, each trial starts zero-shot from a fresh workspace and session (with starter robot documentation and tools only), under a 30-minute time limit and with no code or experience carried over from earlier trials. Across the 3 trials per task, we vary not only the initial tabletop layout, but also the robot arm's starting position and orientation, and judge success directly from the final physical scene.

Each video shows the fixed front camera view of one trial at 10× speed; the counter at the top left shows the elapsed recording time. The time under each video is the end-to-end execution time, including model reasoning, code execution, real camera observation, physical robot motion, and any recovery. Faces and identifying marks in the lab are blurred. Under each video, “Commands and code” opens the agent's key commands and code for that trial alongside the video.
